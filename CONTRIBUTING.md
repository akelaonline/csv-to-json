# Contributing

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Use Node.js 20.16+ (Node 22 or 24 recommended).
3. Run `npm install`.
4. Run `npm run check` and `npm test` before opening a pull request.
5. Keep parser changes bounded: uploads are untrusted input, so new formats must include size/complexity controls and tests.
6. Do not commit sample files containing personal, confidential or malicious data.

For security issues, follow `SECURITY.md` instead of opening a public bug report.
